
# Weather Forecast Application

A simple, responsive weather application built using Python, Flask,
HTML, CSS, and JavaScript.

## Features

- Search weather by city name
- Display current temperature and feels-like temperature
- View humidity, wind speed, and precipitation
- View a 10-day weather forecast
- Display daily maximum and minimum temperatures
- View daily precipitation probability
- Display weather conditions with icons
- Handle invalid city names and API errors

## Technologies Used

- Python
- Flask
- Requests
- HTML
- CSS
- JavaScript
- Open-Meteo API

## How to Run Locally

### 1. Clone the repository

git clone https://github.com/YOUR_USERNAME/weather-forecast-app.git

### 2. Open the project folder

cd weather-forecast-app

### 3. Create a virtual environment

python3 -m venv .venv

### 4. Activate the environment

source .venv/bin/activate

### 5. Install the dependencies

python -m pip install -r requirements.txt

### 6. Start the application

python app.py

### 7. Open the application

http://127.0.0.1:5000

## API Endpoints

- Open-Meteo Geocoding API:
  https://geocoding-api.open-meteo.com/v1/search

- Open-Meteo Forecast API:
  https://api.open-meteo.com/v1/forecast
